# Cima

A doctor-facing AI medical scribe demo built with Next.js 16, React 19, Tailwind CSS 4, Motion, and Lucide icons.

The demo covers the complete consultation loop: patient selection, consent-gated recording, crash recovery, visible processing, structured note review, direct editing, scoped AI revision with a before/after diff, transcript evidence, version history, and signed-note locking.

All patient and visit information is synthetic. Audio capture, transcription, authentication, and persistence are represented by realistic front-end states; no clinical backend is connected.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
```
